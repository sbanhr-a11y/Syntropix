## Experience system
- WCAG 2.2 AA release floor.
- 44×44 CSS px preferred interactive target.
- strong visible focus; full keyboard operation.
- semantic landmarks and heading hierarchy.
- accessible labels/errors/status announcements.
- 200% zoom and reflow acceptance.
- reduced-motion path and non-WebGL/static fallback.
- mobile designed intentionally, not desktop stacked.
- near-black + warm off-white + restrained sage/gold; gold is accent, not decoration.
- varied editorial rhythm; avoid repeated equal-weight card grids.
- real product visuals carry proof.

## Performance contract
- 3D pauses when hidden/off-screen.
- prefers-reduced-motion receives static/final-state experience.
- mobile may use reduced visual complexity.
- WebGL failure must preserve a premium comprehensible fallback.
- images/fonts/scripts optimized and non-critical work deferred.
- performance is a release gate, not post-launch cleanup.

## HARD PROTECTED BOUNDARY
V7 public-site work MUST NOT modify behavior, code, data, routes, APIs, auth, persistence, styling contracts, or deployment configuration for:
- Syntropix Command / admin
- External Reviewer Programme
- reviewer authentication, legal acceptance, conflict declarations/clearance
- reviewer assignments, invitations, drafts, submissions, audit history
- assessment runtime and scoring
- AC/DC Horizon runtime
- Supabase/database/schema/RLS
- Render/backend/API/email services
- production reviewer records or workflows

Any PR touching a protected surface is blocked pending explicit separate authorization.

D. Performance gate — Core Web Vitals-oriented audit; 3D/fallback behavior.
E. Functional gate — nav, CTAs, forms, public journeys, assessment links.
F. Protected regression gate — Command/reviewer/runtime invariants unchanged.
G. Human approval gate — no merge/deploy to main/production without explicit approval.

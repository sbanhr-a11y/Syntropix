# Syntropix Credibility Assets Pack

Status: Controlled working asset pack
Version: 1.0
Date: 2026-09-23

This directory operationalises the public credibility architecture without creating evidence that does not exist.

## Asset set
1. `instrument-technical-document-template-v1.md` — version-controlled full technical-document standard for every proprietary instrument.
2. `enterprise-due-diligence-pack-v1.md` — enterprise security/privacy/procurement response pack.
3. `dpa-working-draft-v1.md` — non-executed DPA working draft for legal review and client-specific completion.
4. `controlled-product-walkthrough-v1.md` — governed demo/walkthrough script and evidence rules.
5. `case-study-evidence-pack-v1.md` — evidence capture, approval and publication standard for first real deployments.
6. `asset-register-v1.csv` — ownership/status register.
7. `scientific-claims-redline-v1.md` — controlled boundary for scientific/predictive/clinical claims.
8. `validation-study-protocol-v1.md` — staged empirical-validation protocol covering content, response process, reliability, structure, external evidence, fairness and norms.
9. `assessment-version-change-control-v1.md` — semantic-version and evidence-transfer standard for instrument changes.
10. `validation-evidence-roadmap-v1.md` — staged study sequencing and Suite v2 prioritization.
11. `suite-v2/` — implementation register plus ten exact-version Suite v2 technical documents.

## Non-negotiable publication boundary
No reliability coefficient, validity result, norm, benchmark, customer logo, testimonial, security certification, compliance status or business outcome may be published unless supported by a version-specific evidence record and the required approval. Illustrative demonstrations must remain labelled illustrative.

## Version discipline
Evidence attaches to the exact instrument, scoring key, language, administration mode and intended population studied. Material changes trigger impact review and, where necessary, re-validation. Instrument semantic versioning is governed by `assessment-version-change-control-v1.md`; evidence transfer must be explicitly classified rather than assumed.

## Validation discipline
The empirical programme is governed by `validation-study-protocol-v1.md`. External research supports construct selection and hypotheses; it does not establish Syntropix-specific reliability, validity, norms, fairness or predictive utility. Discovery and confirmation evidence should remain analytically distinct where feasible.

## Release discipline
These files are documentation assets only. They do not alter assessment scoring, authentication, payments, enterprise runtime, database schema or production application behaviour.

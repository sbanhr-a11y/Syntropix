# Syntropix P1 Independent Expert Content Review Pack v1.0

Status: **REVIEW PACK READY / REVIEWS NOT YET COMPLETED**  
Date: 2026-09-25  
Scope: eight P1 developmental instruments

## Purpose

This pack is the controlled reviewer-facing instrument for independent expert content review of:
- CogniMorph Index™
- Cognitive Learning Profiler™
- Commercial Instinct Index™
- Executive Leadership Index™
- Managerial Effectiveness Index™
- Metacognitive Executive Assessment™
- Self-Limiting Belief Auditor™
- Strategic Inversion Diagnostics™

The review asks whether the current item content adequately represents the intended developmental constructs and whether wording introduces construct contamination, clinical drift, social-desirability pressure, cultural unfairness, redundancy or interpretive overreach.

It is **not** a request for reviewers to certify that an instrument is “valid.”

## Reviewer panel design

Recommended minimum **5 independent reviewers per instrument**, with at least:
1. one psychometrics / psychological measurement expert;
2. one organizational/work psychology expert;
3. one construct-domain expert;
4. one HR/leadership-development practitioner familiar with the target population;
5. one accessibility/plain-language/cultural-context reviewer.

For SLBA, at least one reviewer should be qualified to identify clinical-language and stigma risks.  
For CII, at least one reviewer should have evidence-based sales/industrial-organizational expertise.  
For ELI/MEI, at least one reviewer should have leadership measurement or multi-source leadership research expertise.  
For MEA/CLP/SID, at least one reviewer should be familiar with cognition/metacognition/decision research and able to distinguish self-report disposition from demonstrated cognitive ability.

## Independence and conflict rules

Reviewer records must capture:
- reviewer ID;
- qualifications and relevant expertise;
- organization/affiliation;
- whether the reviewer contributed to original item writing;
- financial/commercial relationship with Syntropix;
- other material conflict;
- date and version reviewed.

A reviewer who authored an item may comment but should not be the sole independent reviewer for that item/construct.

## Materials supplied to reviewer

For the assigned instrument provide:
- current frozen item set and scoring direction;
- P1 Construct & Pilot Architecture v1.0;
- P1 Literature Evidence Tables v1.0;
- current technical document;
- intended-use and prohibited-use boundaries;
- this review form.

Do not provide participant outcome data before content ratings are completed if doing so could bias the content judgment.

# Part A — Construct-level review

For each dimension rate 1–4:
1 = serious problem / not defensible
2 = substantial revision needed
3 = acceptable with minor revision
4 = strong / clearly defensible

| Field | Rating |
|---|---:|
| Construct definition is clear | |
| Construct is meaningfully distinct from adjacent dimensions | |
| Explicit exclusions are adequate | |
| Intended developmental interpretation is appropriate | |
| Literature family is conceptually relevant | |
| Items appear capable of sampling the construct breadth | |
| Risk of clinical/diagnostic interpretation is controlled | |
| Risk of identity-labelling is controlled | |
| Context/culture dependence is appropriately bounded | |
| Intended use does not exceed what content alone can support | |

Required comments:
- What is missing from the construct?
- What should be excluded?
- Which adjacent construct is most likely to contaminate this dimension?
- Is the dimension name itself defensible?
- Would a reasonable participant interpret the label more strongly than the evidence permits?

# Part B — Item-level rating

For every item, rate:

| Criterion | Scale |
|---|---|
| Relevance to intended dimension | 1–4 |
| Clarity | 1–4 |
| Construct specificity | 1–4 |
| Behavioural/context specificity | 1–4 |
| Cultural/context portability | 1–4 |
| Accessibility/plain language | 1–4 |
| Social-desirability pressure | 1–4 where 4 = severe risk |
| Construct contamination | 1–4 where 4 = severe risk |
| Clinical/identity-labelling risk | 1–4 where 4 = severe risk |
| Reverse-wording confusion, if applicable | 1–4 where 4 = severe risk |

Reviewer recommendation:
**RETAIN / REVISE / RETIRE / COGNITIVE-TEST / SPLIT DOUBLE-BARREL**

Required rationale for every REVISE/RETIRE recommendation.

# Part C — Mandatory red-flag checks

Flag YES/NO for each item:
- [ ] asks two behaviours/ideas at once;
- [ ] uses an absolute such as always/never that makes endorsement unrealistic;
- [ ] embeds a socially obvious “good leader/good employee” answer;
- [ ] assumes positional authority the respondent may not possess;
- [ ] confounds opportunity/resources with capability;
- [ ] attributes a contextual/system problem solely to the individual;
- [ ] implies intelligence, brain function or neurological capability;
- [ ] sounds like mental-health diagnosis or symptom screening;
- [ ] implies moral worth or character judgment;
- [ ] embeds culturally narrow assumptions;
- [ ] requires industry knowledge irrelevant to the intended construct;
- [ ] duplicates another item without adding content coverage;
- [ ] reverse-keying changes meaning rather than direction;
- [ ] cannot be answered meaningfully without a time frame;
- [ ] asks participants to report an outcome they may not actually know.

# Part D — Instrument-specific review modules

## CogniMorph Index™
Reviewers must specifically examine:
- whether ALOR is learning orientation rather than self-rated intelligence;
- whether ERAE separates learning from errors from emotional toughness;
- whether CTAP stays non-clinical and does not imply physiological stress measurement;
- whether FRUP measures feedback processing rather than compliance;
- overlap with Coachability Quotient™, MEA and CLP.

## Cognitive Learning Profiler™
Reviewers must specifically examine:
- whether RKEX/TRSY language incorrectly implies demonstrated cognitive performance;
- far-transfer overclaim risk in TRSY;
- whether ADUN rewards novelty rather than evidence-based updating;
- whether DGAD confounds access/exposure with adaptability;
- whether behavioural tasks would be necessary to support stronger interpretations.

## Commercial Instinct Index™
Reviewers must specifically examine:
- obvious desirability in IUIN;
- whether REJR rewards persistence when stopping is rational;
- cultural/channel assumptions in SOIN;
- whether NEGC confuses calmness with negotiation competence;
- organizational-system confounding in PIPD;
- whether SOLC maps to adaptive selling without overclaiming performance prediction.

## Executive Leadership Index™
Reviewers must specifically examine:
- construct redundancy across 200 items;
- fatigue/repetition risk;
- whether 20 items per dimension add genuine content breadth;
- whether TPSC can reasonably be assessed from manager self-report;
- whether VABI/INSP/SNBU/ORUI are distinguishable;
- whether CDQL measures composure rather than actual decision quality;
- whether any item assumes line-management authority.
The panel must make an explicit recommendation:
**FULL 200-ITEM FORM DEFENSIBLE / REDUCE BEFORE PILOT / MATRIX-SAMPLING STUDY REQUIRED / MAJOR REDESIGN REQUIRED.**

## Managerial Effectiveness Index™
Reviewers must specifically examine:
- whether five items adequately represent each ELI domain;
- whether selected items overrepresent easy-to-observe or socially desirable behaviours;
- whether the MEI should report all ten scores;
- whether “Managerial Effectiveness” is too strong a label for a self-report developmental profile.
The panel must make an explicit recommendation on short-form content coverage before empirical linking work.

## Metacognitive Executive Assessment™
Reviewers must specifically examine:
- circularity of self-rated calibration;
- neurological/executive-function interpretation risk;
- whether AUNV items distinguish probabilistic judgment from risk appetite;
- whether MREG requires scenario evidence;
- which dimensions require objective/behavioural companion tasks.

## Self-Limiting Belief Auditor™
Reviewers must specifically examine:
- replace/avoid clinicalized “impostor syndrome” concepts;
- whether FRAP recognizes structural bias/context rather than locating all discrepancy inside the individual;
- whether EXAG mistakes legitimate governance constraints for lack of agency;
- whether TBAV distinguishes prudent delay from avoidance;
- whether RSOR wrongly reframes real scarcity as an individual defect;
- stigma, moralizing and identity-labelling risks.

## Strategic Inversion Diagnostics™
Reviewers must specifically examine:
- whether “first-principles” has a sufficiently bounded operational definition;
- whether SOFC claims foresight rather than self-reported consideration of consequences;
- whether ASAU is distinguishable from generic openness;
- whether CXNV is too broad;
- whether structured scenarios are needed before the instrument can claim reasoning-quality relevance.

# Part E — Quantitative summary

For each dimension calculate:
- item-level median relevance;
- item-level median clarity;
- proportion of items with relevance <3;
- proportion of items with severe (4) social-desirability risk;
- proportion with severe construct-contamination risk;
- reviewer agreement distribution;
- content coverage gaps.

Optional CVI-style summaries may be computed for transparency but **must not be used as mechanical pass/fail rules**.

No item should be retained solely because a numeric index exceeds a threshold; reviewer rationale, construct breadth and minority dissent must be retained.

# Part F — Disagreement resolution

For every disputed item:
1. preserve all original reviewer ratings;
2. document the disagreement;
3. classify the disagreement as construct, wording, culture/context, fairness, accessibility or use-boundary;
4. record whether cognitive testing can resolve it;
5. record final decision and approver;
6. version any meaning-changing revision.

Do not delete dissenting comments from the audit record.

# Part G — Review disposition

Each dimension:
- **ACCEPT FOR COGNITIVE INTERVIEWS**
- **MINOR REVISION THEN COGNITIVE INTERVIEWS**
- **MAJOR CONTENT REVIEW REQUIRED**
- **CONSTRUCT REDEFINITION REQUIRED**
- **PAUSE / RETIRE**

Instrument overall:
- **PROCEED TO RESPONSE-PROCESS STUDY**
- **REVISE BEFORE RESPONSE-PROCESS STUDY**
- **MAJOR REDESIGN**
- **PAUSE / RETIRE**

No disposition means “validated.”

# Part H — Evidence effect after completed review

A completed, independently reviewed pack may contribute to CTE and CE evidence. It does not by itself support:
- reliability;
- factor structure;
- convergent/discriminant validity;
- criterion/predictive validity;
- fairness;
- norms;
- consequential use.

Governance may move CE/CTE from IN PROGRESS toward SUPPORTED only after:
- the actual completed reviewer records are attached;
- material disagreements are resolved;
- any revisions are versioned;
- Governance reviews the exact construct/use interpretation being supported.

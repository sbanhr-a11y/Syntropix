# Validation Evidence Roadmap — v1

Date: 2026-09-23  
Status: CONTROLLED PLANNING DOCUMENT

## Objective

Build defensible, version-specific evidence without attempting to validate every Syntropix instrument at once. Prioritization is based on methodological feasibility, recruitment access, safeguarding complexity and commercial usefulness—not on a claim that one construct is more scientifically important than another.

## Wave 0 — common infrastructure

Complete once for all studies:
- participant information/consent template;
- research opt-in separated from product purchase/access;
- de-identified research dataset schema;
- duplicate/bot/low-effort response rules;
- analysis repository structure;
- evidence-ID convention;
- preregistration template;
- cognitive-interview script;
- content-review form;
- data-retention/deletion workflow;
- study closeout template;
- version/checksum capture.

## Wave 1 — lower-complexity adult/work instruments

Recommended first instruments:
1. Career Navigation Index
2. Work-Life Fit Index
3. Social Signal Profile
4. Adaptive Capacity Index

Rationale:
- adult-oriented use;
- constructs can be studied without clinical framing;
- recruitment can span working adults/professionals;
- likely easier external-measure selection;
- findings can stress-test the Suite v2 four-factor / three-item-per-factor architecture before scaling the same design pattern to all ten instruments.

Minimum sequence per instrument:
content review → cognitive interviews → discovery pilot → item/reliability review → factor-structure decision → version freeze/revision → independent confirmation.

Do not pool discovery and confirmation merely to reach a larger n.

## Wave 2 — relationship/emotion and life-stage instruments

- Relationship Dynamics Profile
- Emotional Agility Profile
- Life Chapter Compass
- Generativity & Legacy Index
- Intergenerational Bridge Profile

Additional safeguards:
- stronger sensitivity review for relationship/emotion wording;
- age-appropriate recruitment matching the intended product population;
- explicit distinction between reflective development and mental-health interpretation;
- life-stage instruments should not recruit a broad adult sample and then generalize to 35+/40+ intended populations.

## Wave 3 — Identity Compass

Identity Compass should be validated only after its product/audience policy is reconciled.

Current state:
- definition metadata: 14–26;
- catalogue/self-serve product: 18+;
- governance: under-18 disabled.

Before study recruitment, choose and document one intended validation population:
- adults 18–26 only; or
- a future youth/adult programme with separate guardian/assent, safeguarding, jurisdiction and data-handling architecture.

Do not recruit minors merely because the historical metadata says 14–26.

## Study planning targets

For the 12-item / four-factor Suite v2 pattern:
- cognitive interviews: enough participants to expose interpretation problems across relevant subgroups; justify saturation rather than claiming a fixed universal n;
- discovery pilot: ordinarily several hundred usable responses when feasible;
- factor confirmation: independent sample, also several hundred where feasible;
- fairness/invariance: sample requirements may materially exceed the core factor-analysis sample, depending on number of groups and model complexity.

The existing enterprise blueprint uses n>=300 and >=10 complete respondents per item as conservative readiness gates for its 30-item enterprise instruments. That rule is not copied mechanically to Suite v2; achieved sample size must be justified for each model and purpose.

## Predefined Suite v2 analyses

At minimum:
- response completeness and exclusions;
- item distribution / floor-ceiling review;
- reverse-item behaviour;
- corrected item-rest relationships;
- omega primary, alpha supplementary;
- ordinal factor analysis;
- four-factor model vs plausible alternatives;
- factor correlations;
- test–retest where conceptually relevant;
- convergent/discriminant evidence;
- subgroup comparability when sample supports it;
- sensitivity analysis for low-effort responding.

No interpretation band calibration should be represented as normative until a separate benchmark/norm design exists.

## External evidence strategy

For each construct, select established external measures only where:
- use/licensing permits;
- evidence is documented for the target population;
- overlap is theoretically justified;
- Syntropix does not copy proprietary items.

External-measure evidence supports relations between scores; it does not make the Syntropix instrument identical to the comparator.

## Decision rules after discovery

Possible outcomes:
- retain 1.0.0 for confirmation;
- revise wording only → assess PATCH vs MINOR under change-control;
- retire/replace weak item(s) → MINOR and restart structural evidence for the changed version;
- revise construct architecture → MAJOR;
- pause instrument if structure/content cannot be defended.

“Poor” pilot results are not publication failures; they are design evidence.

## Public-claim progression

Before empirical data:
DEVELOPMENTAL / RESEARCH-INFORMED / VALIDATION IN PROGRESS

After useful pilot:
PILOT EVIDENCE AVAILABLE — describe exact findings, not “validated”

After independent structural/other evidence:
SUPPORTED FOR SPECIFIED DEVELOPMENTAL INTERPRETATION — only if the accumulated evidence justifies that exact interpretation

Consequential employment use remains a separate evidence/legal/fairness gate.

A study cannot be marked READY until every applicable item is complete.

## Scientific design
- [ ] Intended interpretation is explicitly defined.
- [ ] Instrument/version/scoring are frozen.
- [ ] Construct map exists.
- [ ] Content review completed or scheduled before pilot.
- [ ] Cognitive-interview findings incorporated or explicitly deferred with rationale.
- [ ] Discovery vs confirmation role is declared.
- [ ] Sample-size rationale documented.
- [ ] Primary analyses and sensitivity analyses preregistered.
- [ ] External measures are licensed/permitted for planned use.
- [ ] No planned analysis is described as causal without a causal design.

## Version integrity
- [ ] Repository commit captured.
- [ ] Item-set reference/checksum captured.
- [ ] Scoring specification captured.
- [ ] Report version captured.
- [ ] Locale captured.
- [ ] Evidence-transfer status from any prior version documented.

## Privacy / consent
- [ ] Study-specific participant information completed.
- [ ] Consent wording approved.
- [ ] Research opt-in is separate from unrelated commercial entitlement.
- [ ] Data fields follow minimum-necessary principle.
- [ ] Identity/contact table separated from analysis data.
- [ ] Retention/deletion periods defined.
- [ ] Withdrawal/deletion process defined.
- [ ] Processor/collaborator data flows documented.
- [ ] Employment-setting access boundary documented where relevant.

## Safeguarding
- [ ] Minimum participant age matches current governance.
- [ ] Any narrower product age positioning is respected.
- [ ] Under-18 recruitment is blocked unless a separate approved youth protocol exists.
- [ ] Sensitive/relationship/emotion wording has undergone risk review.
- [ ] Escalation language does not imply clinical care unless a legitimate clinical referral process exists.

## Technical quality
- [ ] Duplicate/bot controls defined.
- [ ] Low-effort/speeding rules defined before outcome review.
- [ ] Missing-response behaviour tested.
- [ ] Scoring fixtures pass.
- [ ] Study environment tested on supported devices/browsers.
- [ ] Error logging does not expose response data unnecessarily.
- [ ] Export schema verified against de-identified dataset standard.

## Analysis reproducibility
- [ ] R/Python environment pinned.
- [ ] Package manifest/lock recorded.
- [ ] Random seed policy defined.
- [ ] Analysis repository/path created.
- [ ] Output directory/evidence IDs reserved.
- [ ] Raw → cleaned → analysis-ready transformations scripted.

## Publication discipline
- [ ] Current public claims captured before study.
- [ ] Possible claim changes predefined.
- [ ] No “validated”, normed, predictive, bias-free or causal claim is pre-authorized.
- [ ] Null/adverse results will remain in the evidence record.
- [ ] Technical-document update owner assigned.

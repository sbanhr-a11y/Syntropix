# Syntropix Manager Signal — Alpha Scenario Bank v0.1

Date: 2026-09-23
Status: RESEARCH DRAFT / NOT FOR CANDIDATE USE
Product: Manager Signal

## Purpose

This is the first controlled scenario bank authored under the Syntropix Assess construct, complexity, scoring, integrity and UX standards.

It is **not validated**, **not calibrated**, and **not approved for production selection**.

## Response instruction

Default candidate instruction for the alpha bank:

> Read the situation and choose the response that most closely reflects what you would do in that situation. There may be more than one reasonable option. Use only the information provided unless the scenario explicitly asks you to infer or request additional information.

This behavioural-tendency framing is intentional. Response instructions materially influence what SJTs measure.

## Alpha-bank architecture

18 stateful testlets:
- 3 People Judgment
- 3 Execution & Prioritisation
- 3 Decision & Evidence Quality
- 3 Stakeholder Judgment
- 3 Learning & Adaptive Judgment
- 3 AI-era Management Judgment

Each testlet has:
- Stage 1 decision
- Stage 2 new evidence / consequence
- Stage 3 challenge-back or revised decision

Approximate alpha evidence units: **54**

The final operational form is still expected to use about 30–34 scored decisions, sampled from a larger calibrated bank.

## Complexity target

Across the alpha bank, testlets generally progress:
CX2 → CX3 → CX3/CX4.

This is intentional: the bank is designed to test how judgment changes as context becomes less clear and consequences rise.

## Scoring

Current scores are expert-key hypotheses only:
0 = poorly aligned evidence
1 = limited evidence
2 = reasonable evidence
3 = strong evidence

They must be reviewed by SMEs and empirically evaluated before operational use.

## Scientific boundary

External SJT and selection research informs the method. It does not validate these Syntropix testlets.

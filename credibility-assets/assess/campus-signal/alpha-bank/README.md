# Campus Signal — Alpha Bank v0.1

Status: RESEARCH DRAFT / NOT FOR CANDIDATE USE

Current alpha components:

- Applied Reasoning: 6 decision units
- Learn → Apply prototype: 8 scored decisions including challenge-back
- Workplace Judgment: 6 decision units
- Communication / Ownership probes: 4 decision units
- AI Work Judgment: 5 decision units

Current total: **29 scored decision units**

The final v1 design hypothesis remains approximately 34 decisions / 35–40 minutes. This alpha intentionally begins smaller so candidate cognitive interviews can tell us where additional evidence is genuinely needed.

## Key design rules

- no university prestige/GPA scoring;
- no hidden professional knowledge;
- no accent/voice analysis;
- no abstract IQ branding;
- applied reasoning is proportionate;
- Learn→Apply rules remain accessible in v0.1;
- candidate-facing option order must be randomized where appropriate;
- current keys are expert hypotheses only;
- all items require fairness/accessibility review and empirical evaluation.

# Campus Signal Learn → Apply — Candidate UX Notes v0.1

Status: UX PROTOTYPE SPECIFICATION

## Screen 1 — Learn

Two-column desktop layout:

Left:
- Aster system overview
- four attribute definitions

Right:
- routing rules
- one worked example

CTA:
**Start practice**

Candidate may revisit this reference during scored decisions unless later research supports a memory component.

## Screen 2 — Practice

One unscored practice case.

Candidate selects route.

System explains the rule application.

Purpose:
teach interaction mechanics, not coach scored content.

## Screen 3 — Scored application

Left rail:
**Reference rules** collapsible but always accessible.

Main:
case attributes presented as compact evidence cards.

Bottom:
four response options.

Progress:
“Application 2 of 5”

No “easy/hard” labels.

## Screen 4 — New rule

Visually distinct banner:

**PROCESS UPDATE**

“During Peak Window, use this additional rule…”

Candidate explicitly acknowledges the update.

## Screen 5 — Transfer

New cases use the updated system.

The reference panel now includes Rule 5 with a **New** marker.

## Screen 6 — Challenge-back

Show:
**Situation changed**

Do not reveal previous score.

Summarize only the previous relevant facts and the new information.

Ask candidate to decide again.

## Accessibility

- rules remain text, not image-only;
- keyboard navigation;
- cards read in logical screen-reader order;
- no colour-only status;
- allow zoom/reflow;
- no memory-dependent hiding of rules in v0.1;
- timing accommodation supported.

## Premium visual direction

Use Syntropix V6:
- near-black outer shell;
- warm ivory reading surface;
- champagne section markers;
- slate evidence cards;
- emerald confirmed/current route cues;
- restrained motion when new rules appear.

The experience should feel like learning a real work system, not sitting a reasoning exam.

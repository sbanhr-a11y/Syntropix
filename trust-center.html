CONTROL BOUNDARIES

Security claims stay at the layer Syntropix actually controls.

Using a provider that holds a certification does not make Syntropix itself certified. The relevant question is how the whole system is configured, governed and operated.

IDENTITY & ACCESS

Least privilege and server-side secrets.

Privileged credentials are kept out of public browser code, with role and workflow boundaries for sensitive operations.

DATA PURPOSE

Access follows the use case.

Developmental data should not become unrestricted enterprise visibility simply because it exists in the platform.

RELEASE SAFETY

Presentation changes are gated.

Automated regression controls help keep assessment, auth and enterprise runtime logic separate from website redesign work.

CONFIDENTIALITY

Aggregation is not magic anonymity.

Prism360 and employee-experience workflows must consider group size, role context and potentially identifying free text.

AI BOUNDARY

Developmental assistance, not autonomous employment decisions.

AI-supported reflection should not be represented as a clinical judgement, definitive talent verdict or substitute for appropriate human review.

GLOBAL DEPLOYMENT

Cross-border questions are deployment-specific.

Data-processing roles, retention, lawful basis and transfer mechanisms need to match the client geography and workflow.

DATA LIFECYCLE QUESTIONS

The enterprise conversation should cover more than a security checkbox.

Before deployment, Syntropix and the client should define the data category, purpose, visibility, retention, deletion path and evidence/reporting boundary for the workflow.

01 / COLLECT

What is necessary?

Define participant, rater, assessment, survey or client-administration data required for the stated purpose.

02 / ACCESS

Who needs to see what?

Separate participant, enterprise, assessor, coach and administrative visibility rather than assuming a single access model.

03 / RETAIN

How long should it remain?

Retention should be purpose-based and contractually aligned rather than indefinite by default.

04 / DELETE

What is the deletion path?

Rights and deletion workflows should account for operational, legal and contractual obligations applicable to the data.

Security · privacy · governance

Trust is a system, not a badge.

Trust comes from explicit boundaries, least privilege, traceable administrative actions, disciplined releases and honest claims. Infrastructure-provider certifications do not automatically become Syntropix certifications.

Control boundary

Syntropix responsibility

Application & operations

Authorization, application configuration, assessment-data handling, tenant isolation, retention choices, administrative access, release discipline and incident response remain Syntropix responsibilities.

Provider responsibility

Underlying infrastructure

Hosting, database and other providers operate their own controls and publish their own compliance material. Their certifications apply only within their documented service boundaries.

Application security principles

Identity & access

Authenticated authorization, least privilege, server-side privileged secrets and explicit role boundaries. Browser-visible code must never contain service-role or equivalent privileged credentials.

Data isolation

Row-level or equivalent authorization controls where exposed data requires user or tenant isolation, with deny-by-default handling for sensitive datasets.

Auditability

Sensitive administrative workflows should create traceable events. Auditability complements—not replaces—authorization.

Release safety

Material changes are expected to pass regression/security checks before production. Assessment-engine changes require parity testing so presentation work cannot silently alter scoring.

Assessment-data principles

  • collect only information required for a stated workflow;
  • separate developmental interpretation from clinical, neurological or diagnostic claims;
  • attach scoring and evidence to an instrument version;
  • do not expose population percentiles until defensible normative evidence exists;
  • apply explicit retention/deletion rules to each workflow;
  • treat enterprise access as purpose-bound rather than unrestricted visibility into an individual’s developmental story.

Prism360 confidentiality

Multi-rater reporting uses minimum reporting thresholds for confidential groups. A threshold reduces disclosure risk; it cannot guarantee that identity will never be inferred from context. Groups that do not safely meet the applicable threshold should be suppressed or combined only when the resulting group remains sufficiently protected.

Evidence and trust belong together

Security claims and psychometric claims follow the same principle: say only what the evidence supports. See Evidence before adjectives → for Syntropix’s claims ladder, validation mechanism and bibliography.

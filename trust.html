Trust is a system, not a badge.

This page distinguishes Syntropix controls from the certifications and controls of infrastructure providers. Use of a certified hosting or database provider does not make Syntropix itself SOC 2 or ISO 27001 certified.

Infrastructure boundary

Syntropix uses technology providers that publish their own security and compliance information. Their certifications apply within their respective service boundaries. Syntropix remains responsible for application configuration, authorization, data handling, retention, access management and its own operational controls.

Application security principles

  • least-privilege access and authenticated authorization;
  • row-level access controls where exposed data requires tenant/user isolation;
  • privileged secrets kept server-side rather than in browser code;
  • audit logging for sensitive administrative workflows;
  • private storage and expiring access patterns for sensitive files where implemented;
  • dependency and security review before production releases.

Privacy & assessment data

We aim to collect only data needed for the stated service, separate purposes where practical and define retention/deletion for each workflow. See the Privacy Policy for current public terms.

Prism360 confidentiality

Multi-rater reporting uses minimum reporting thresholds for confidential groups. A threshold is a reporting safeguard, not an absolute guarantee that identity can never be inferred from context. Groups that do not safely meet the applicable threshold should be suppressed or combined only when the combined group itself remains sufficiently protected.

# Enterprise System Assessments — Production QA

## Release checks
- Enterprise-only placement; consumer insight trio remains on Professionals.
- Licence invitation/session required before assessment starts.
- 30 items per instrument, 5-point scale, versioned definitions.
- Report separates employee, manager and organisation hypotheses.
- No normative, diagnostic or predictive claim while validation stage is content-review/sample_n=0.
- Research reuse is optional and requires explicit participant consent.
- Validation payload uses `items`, `researchNoticeVersion`, instrument version and scoring version.
- If consent is declined, the participant still receives the report and no validation-response request is sent.

## Validation release gates
Do not promote an instrument to psychometrically evaluated until prespecified sample, reliability, factor-structure and fairness checks are completed. Do not enable selection use or normative reporting merely because internal consistency is acceptable.
